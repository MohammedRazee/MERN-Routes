This is the About Us Page

This project is a teaching example built to walk through core Express concepts: defining routes with app.get(), serving static HTML with res.sendFile(), and reading query parameters from incoming requests.

What's Under the Hood

  • Three simple routes: /, /about, and /contact
  • A /search route that filters an in-memory list of movies by genre
  • Plain HTML templates served straight from the templates/ folder
  • Shared styling served from the public/ folder

Built for learning Express & Node routing.
